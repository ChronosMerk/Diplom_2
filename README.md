# Тестовый фреймворк для API Stellar Burgers

Этот проект представляет собой тестовый фреймворк на Python для API сервиса Stellar Burgers. Он использует `pytest` для написания и запуска тестов, `requests` для взаимодействия с API, и `allure-pytest` для создания отчетов о тестировании.

## Описание проекта

Проект содержит набор автотестов для проверки основных функций API Stellar Burgers, включая:
- Регистрацию пользователей
- Авторизацию пользователей
- Обновление данных пользователей
- Создание заказов
- Получение заказов

## Структура проекта

- `api_methods/`: Модули для взаимодействия с различными частями API.
- `data/`: Модули с тестовыми данными и сообщениями.
- `tests/`: Тестовые файлы с наборами тестов.
- `helpers.py`: Вспомогательные функции для тестов.
- `conftest.py`: Файл конфигурации Pytest с фикстурами.
- `requirements.txt`: Список зависимостей проекта.

## Настройка проекта

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd <имя папки>
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # для Windows: venv\Scripts\activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

## Запуск тестов

Для запуска тестов и создания отчета Allure выполните следующую команду:

```bash
pytest --alluredir=allure-results
```

После выполнения тестов, вы можете сгенерировать и открыть HTML-отчет с помощью Allure:

```bash
allure serve allure-results
```
